# Frontend

This directory contains the React and Vite client for the Course Registration System.

For full project documentation—including prerequisites, backend and frontend setup, demo accounts, database seeding, and Telegram/Discord configuration—see the [project README](../README.md).

## Client commands

```bash
npm install
npm run dev
```

Other available commands:

```bash
npm run build
npm run lint
```

The client expects the API at `http://localhost:5001/api`.
